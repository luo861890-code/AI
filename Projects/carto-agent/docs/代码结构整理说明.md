# CartoAgent 代码结构整理说明

> 本文档记录本次「去重与模块化」整理后的代码结构，重点说明
> 1. 后端几何工具函数的集中与去重；
> 2. 前端「做图渲染」与「编辑渲染」的职责边界；
> 3. 已清理的废弃文件。
>
> 本文档反映整理后最新状态，与 `docs/项目结构说明.md` 中已过时的
> 「经典 JS 前端（frontend/src/）」相关描述以本文档为准。

## 一、整理目标

1. **消除重复实现**：同一几何算法（射线法、球面面积、凸包、Haversine 等）
   原先散落在多个 service 中，本次集中到单一模块。
2. **理清模块职责**：明确前端两套地图渲染各自的服务场景，避免职责混淆。
3. **清理废弃残留**：删除已不再被引用、指向不存在目录的旧前端文件。

## 三、后端几何工具函数模块化

### 3.1 新增模块 `backend/app/utils/geometry.py`

集中 6 个纯几何函数（无业务依赖，仅依赖标准库 `math`）：

| 函数 | 功能 | 约定 |
|------|------|------|
| `_point_in_ring(pt, ring)` | 射线法判断点是否在环内 | `pt=[lat,lng]`；带除零保护 |
| `_ring_area_km2(ring)` | 环的球面面积（km²） | `ring=[[lat,lng],…]` |
| `_convex_hull(points)` | Andrew 单调链凸包 | 返回闭合环 |
| `_interior_point(ring)` | 多边形内点（质心优先 + 扫描线兜底） | 返回 `[lat,lng]` |
| `_haversine(p1, p2)` | 两点球面距离（km） | `p=[lat,lng]` |
| `_line_len_km(line)` | 折线总长度（km） | `line=[[lat,lng],…]` |

### 3.2 各 service 的导入调整

| 文件 | 调整 |
|------|------|
| `geo_service.py` | 删除本地 `_point_in_ring` / `_interior_point` / `_ring_area_km2` / `_convex_hull` 定义，改为从 `geometry` 导入 |
| `quality_service.py` | 删除本地 `_point_in_ring` / `_ring_area_km2` / `_haversine` / `_line_len_km` 定义，改为从 `geometry` 导入；清理不再使用的 `import math` |
| `local_geo_service.py` | 统一从 `geometry` 导入 `_convex_hull` / `_ring_area_km2`，修复原先「同一函数从两个来源导入」的混乱 |
| `map_service.py` | 删除重复的 `_point_in_ring` 类方法，改用 `geometry` 公共函数 |

### 3.3 去重对照

| 函数 | 整理前重复位置 | 整理后 |
|------|----------------|--------|
| `_point_in_ring` | `geo_service.py` / `quality_service.py` / `map_service.py`（3 处） | 仅 `geometry.py` 1 处 |
| `_ring_area_km2` | `geo_service.py` / `quality_service.py`（2 处） | 仅 `geometry.py` 1 处 |
| `_convex_hull` | `geo_service.py`（1 处，被 local_geo 局部导入） | 移入 `geometry.py` |
| `_interior_point` | `geo_service.py`（1 处） | 移入 `geometry.py` |
| `_haversine` / `_line_len_km` | `quality_service.py`（1 处） | 移入 `geometry.py` |

## 四、前端做图模块职责边界

前端存在两套地图渲染，**职责不同、不合并**：

| 组件 | 使用场景 | 职责 |
|------|----------|------|
| `LegacyMapPanel.vue` | 主界面（`App.vue` 的 main 视图） | 做图渲染。以 headless 模式复用经典 JS `MapPanel`（`public/legacy/map.js` + `map-lod.js`），保证与 8080/app 行政区划图效果一致（含 LOD 载负量、plain 制图底图、行政图自动取景） |
| `MapCanvas.vue` | 编辑界面（`QgisEditor.vue`） | 渲染 + 编辑。基于 Leaflet 原生 + `leaflet-editable`，承载 QGIS 式几何编辑、自然语言修改、图层样式编辑 |

关键集成点：
- `frontend/vue-app/index.html` 在 `<body>` 中按顺序加载经典 JS 做图模块，并暴露
  `window.MapPanel / Utils / API / CONFIG`。
- `LegacyMapPanel.vue` 在 `onMounted` 时创建 `MapPanel` 实例，仅初始化做图渲染所需
  状态（headless），并通过 `zoomend → refreshLabels` 绑定载负量 LOD 刷新。
