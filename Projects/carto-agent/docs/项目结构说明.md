# CartoAgent 项目结构与模块说明

> 本文档适用于 `carto-agent`（主项目）与 `carto-agent-1`（同结构副本），
> 用于快速理解代码组织、模块职责与运行方式。

## 一、项目定位

**集成大语言模型（LLM）与知识图谱（KG）的在线地图制图智能体系统**：
用户通过自然语言描述制图需求，系统自动完成"需求理解 → 知识检索 →
任务规划 → 工具调度 → 数据获取 → 地图渲染"，并支持类 ArcGIS/QGIS 的
矢量编辑（绘制、节点编辑、撤销重做、属性编辑、保存回写）。

技术栈：Python 3.10+ / FastAPI / LangChain / Neo4j（可降级内存模式）/
Leaflet / Vue 3 / D3.js / MapLibre（历史版本）。

```

│   │   ├── services/        # 业务服务（智能体 / LLM / 地图 / KG / OSM …）
│   │   └── utils/           # 通用工具函数

│       ├── index.html       # 入口，加载 Leaflet 与经典 JS 做图模块
│       ├── public/legacy/   # 经典 JS 做图模块（MapPanel，供 Vue 复用）
│       │   ├── config.js / utils.js / api.js
│       │   ├── map.js / map-lod.js / map-edit.js
│       │   └── leaflet-editable.js
│       └── src/
│           ├── components/  # 聊天 / 地图 / 图谱 / 图层 / 样式等组件

│   ├── maps.json            # 已生成地图（主文件，超出 10 张自动归档）
│   ├── sessions.json        # 会话历史（消息只存 map_id 引用，不内嵌地图）
│   ├── kg/                  # 知识图谱初始数据（init_data.json 等）
│   └── archive/             # 历史地图归档 + 迁移前数据备份（zip）
```

## 三、后端分层与模块职责

### 3.1 API 层（backend/app/api/）

| 文件 | 职责 |
|------|------|
| `main.py` | FastAPI 入口：挂载路由、CORS、静态前端托管、健康检查 |
| `deps.py` | 依赖注入：单例服务（LLM / KG / OSM / Map / Session / Agent 等） |
| `chat.py` | 会话与消息接口，含 SSE 流式生成端点 |
| `maps.py` | 地图生成 / 查询 / 修改 / 图层编辑 / 导出 / 质量检测 |
| `knowledge.py` | 知识图谱查询 / 图谱构建 / GraphRAG / 文档导入 |
| `settings.py` | LLM Provider / 数据源等运行配置读取与切换 |

### 3.2 服务层（backend/app/services/）

| 服务 | 职责 |
|------|------|
| `agent_service.py` | 智能体编排核心：意图识别 → 知识检索 → 规划 → 工具调度 → 生成 |
| `llm_service.py` | 多 LLM 统一调度（DeepSeek / Ollama / 通义 / OpenAI / 智谱） |
| `map_service.py` | 地图生成与管理、图层编辑、样式、归档 |
| `kg_service.py` | 知识图谱（Neo4j + 内存降级）、实体/关系/约束查询 |
| `graphrag_service.py` | GraphRAG 多跳推理（检索子图 → 接地生成） |
| `rag_service.py` | 制图知识库关键词 + 2-gram 相似度检索 |
| `geotoken_service.py` | GeoToken 地图语言 Token 化预处理 |
| `session_service.py` | 会话与消息持久化（防抖写入） |
| `osm_service.py` | Overpass API 抓取 OSM 地理数据（带磁盘缓存） |
| `local_geo_service.py` | 本地精确 GeoJSON 数据（优先于 OSM） |
| `geo_service.py` | 地理数据处理与边界构建 |
| `data_source_adapter.py` | 多源数据融合适配器（OSM / 高德 / 天地图） |
| `cartographic_planner.py` | KG 优先的制图方案规划器 |
| `cartography_validator.py` | 制图规范校验与质量评分 |
| `quality_service.py` | 五类数据质量检测（拓扑/属性/统计/专题/标注） |
| `export_service.py` | GeoJSON / SVG / PNG 导出 |
| `routing_service.py` | 路径规划（驾车/步行/骑行） |
| `contour_service.py` | DEM 等高线生成 |
| `wiki_service.py` | 重点建筑百科信息 |
| `amap_service.py` | 高德接口封装（地理编码 / POI） |
| `tool_registry.py` | 标准化工具注册体系（OSM 抓取 / 样式 / 渲染 / 质检 / 导出） |

### 3.3 核心层（backend/app/core/）

| 文件 | 职责 |
|------|------|
| `config.py` | Pydantic Settings，自动加载 backend/.env（含密钥注入 os.environ） |
| `constants.py` | 城市 BBOX、地图类型、样式字典、行政中心符号等常量 |
| `kg_ontology.py` | 制图知识图谱本体定义（MapElement/MapSymbol/…） |
| `exceptions.py` | 自定义异常 |

## 四、前端说明

### 4.1 经典 JS 做图模块（frontend/vue-app/public/legacy/）

- 原经典 JS 前端的 UI 已删除，仅保留做图模块供 Vue 复用。
- `index.html` 按顺序加载：`config.js → utils.js → api.js → map.js → map-lod.js → map-edit.js`，
  并暴露 `window.MapPanel / Utils / API / CONFIG`。
- 主界面由 `LegacyMapPanel.vue` 以 headless 模式复用 `MapPanel`（做图渲染 + LOD 载负量）。

### 4.2 Vue 3 前端（frontend/vue-app/）

- 独立 Vite 构建，开发端口 5173（carto-agent）/ 5174（carto-agent-1）。
- 组件化结构：ChatPanel / MapCanvas / KGPanel / LayerPanel / StylePanel /
  QgisEditor / AnalysisPanel / ParamsPanel 等。
- 地图渲染（MapCanvas.vue）与 carto-agent-1 保持一致：
  - features 型图层渲染（区县政区等专题面）
  - LOD 按比例尺分级显隐（规则见 `tools/verify_lod.py`）
  - 行政区划图强制 plain 制图底图 + 全要素取景（maxZoom 10.5）+ 内图廓框线

## 五、数据与存储

| 文件 | 说明 |
|------|------|
| `data/maps.json` | 已生成地图主文件；超过 `MAPS_MAIN_LIMIT`（10 张）自动归档 |
| `data/archive/maps/` | 历史地图按 map_id 独立存放，`get_map` 按需加载 |
| `data/archive/*.zip` | 迁移前完整数据备份（可恢复） |
| `data/sessions.json` | 会话历史；消息仅存 `map_id` + 摘要，不内嵌完整地图 |
| `data/kg/` | 知识图谱初始数据（237 节点 / 803 关系） |
| `backend/data/geo/` | 本地精确地理数据（区县 / 水系 / 路网 / 旅游等） |
| `backend/data/dem/` | SRTM DEM 数据（等高线生成） |

## 六、启动方式

```bash
# 1. 后端（默认 8080；carto-agent-1 可改端口 8081 避免冲突）
cd backend
pip install -r requirements.txt
python ../tools/start_server_noproxy.py        # 无代理启动（保证 OSM 可用）

# 2. Vue 新版前端（可选）
cd frontend/vue-app
npm install
npm run dev                                     # 默认 5173
```

访问：
- Vue 前端：`http://localhost:5173`
- API 文档：`http://localhost:8080/docs`

## 七、常用工具脚本（tools/）

| 脚本 | 用途 |
|------|------|
| `start_server.py` / `start_server_noproxy.py` | 分离式后台启动后端 |

| `test_map_gen.py` | 地图生成接口冒烟测试 |
| `fix_system.py` / `patch_def.py` | 系统修复 / 一次性补丁 |
| `supplement_kg.py` / `export_ontology.py` | 知识图谱扩充 / 本体导出 |
| `evaluate_system.py` | 系统评估 |
| `generate_contours.py` / `download_srtm_wuhan.ps1` | 等高线生成与 DEM 下载 |
| `fetch_osm_wuhan.py` | OSM 数据抓取 |

## 八、代码约定

- 后端：每个模块保留模块级 docstring 说明职责；服务类方法注明输入输出。
- 关键业务链（智能体编排、地图生成、LOD 规则）均有行内注释标注设计依据。
- 前端：组件按功能拆分（面板 / 编辑器 / 状态 / 服务），类型集中在 `types/`。
- 数据文件与密钥不入库（见 `.gitignore`）。
